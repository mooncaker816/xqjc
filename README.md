注：动态版需JS支持，推荐使用 Acrobat Reader。详细情况如下：
> PDF files with animations can be viewed in Acrobat Reader (except on mobile devices),
KDE Okular, PDF-XChange, Foxit Reader, PDF.js (Firefox’ built-in PDF viewer and
extension for Chromium-based Web browsers). To view a local PDF file in the Web
browser, open it by right-click in a file explorer or by starting the Web browser on the
command-line, passing the PDF file name as its argument. The full-screen mode, also
known as Presentation Mode in PDF.js, can be reached via the » button at the right
end of the toolbar. The PDF.js extension for Chromium/Chrome/Edge can be installed
from
https://chromewebstore.google.com/detail/pdf-viewer/oemmndcbldboiebfnladdacbdfmadadm
For animations to play in the Chromium extension, JavaScript needs to be enabled in
the settings:
chrome://extensions/?id=oemmndcbldboiebfnladdacbdfmadadm →
Extension options → Enable active content (JavaScript) in PDFs
Viewing of local files also needs to be enabled in Chromium-based browsers:
chrome://extensions/?id=oemmndcbldboiebfnladdacbdfmadadm →
Allow access to file URLs
